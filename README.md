# PostgreSQL Cafe

PostgreSQL Cafe is a cafe reservation application developed using ASP.NET Core 6.0. This project enables users to make cafe reservations and enhances user experience using modern technologies. It is equipped with technologies such as SignalR, AJAX, PostgreSQL, and MailKit.

## Project Overview

👤 **User Interface**: Provides a user-friendly interface. Users can make cafe reservations and view existing reservation details. AJAX technology is used for making reservations without page refresh, which increases user satisfaction.

## Technologies and Tools Used 🤖

- **.NET Core 6.0**: Used as the core framework for the web application. ✅  
- **PostgreSQL**: Used for database management and storage. ✅  
- **SignalR**: Enables real-time updates for reservations and other statistics. ✅  
- **AJAX**: Allows data operations without page reload, enhancing user experience. ✅  
- **MailKit**: Provides email sending for reservation confirmations and other notifications. ✅  

## SOLID Principles

The project is developed following SOLID principles.

# PostgreSQL Cafe

PostgreSQL Cafe, ASP.NET Core 6.0 kullanılarak geliştirilmiş bir kafe rezervasyon uygulamasıdır. Bu proje, kullanıcıların kafe rezervasyonları yapmasını sağlar ve modern teknolojiler kullanarak kullanıcı deneyimini geliştirir. SignalR, AJAX, PostgreSQL ve MailKit gibi teknolojilerle donatılmıştır.

## Projeye Genel Bakış

👤 **Arayüz**: Kullanıcı dostu bir arayüz sunar. Kullanıcılar, kafe rezervasyonları yapabilir ve mevcut rezervasyon bilgilerini görüntüleyebilirler. Sayfa yenilemeden rezervasyon yapabilmek için AJAX teknolojisi kullanılmıştır, bu da kullanıcı memnuniyetini artırır.

## Kullanılan Teknolojiler ve Uygulamalar

- **.NET Core 6.0**: Web uygulamasının temel çerçevesi olarak kullanıldı. ✅  
- **PostgreSQL**: Veritabanı yönetimi ve depolama için kullanıldı. ✅  
- **SignalR**: Rezervasyon ve diğer istatistiklerin gerçek zamanlı olarak güncellenmesini sağlar. ✅  
- **AJAX**: Sayfa yenilemeden veri işlemleri yapılmasını sağlar, böylece kullanıcı deneyimi geliştirilir. ✅  
- **MailKit**: Rezervasyon onayları ve diğer bildirimler için e-posta gönderimi sağlar. ✅
